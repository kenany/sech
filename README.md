# sech

Calculate the hyperbolic secant of a number.

## Example

``` javascript
import { sech } from 'sech';

sech(Math.PI);
// => 0.08626673833405443
```

## Installation

``` bash
$ npm install sech
```

## API

``` javascript
import { sech } from 'sech';
```

### `sech(x: number)`

Given a _Number_ `x`, returns the hyperbolic secant of `x` as a _Number_.
